# The Great Museum Heist

An interactive, story-driven lesson on **Python functions**. A heist crew stands in for the different kinds of functions, so each concept sticks as a story instead of a definition.

**Single self-contained page, no setup needed. Open `index.html` in a browser.**

## What it covers

| Chapter | Concept | Heist metaphor |
|---|---|---|
| 1 | Why functions exist | A heist needs a crew |
| 2 | Built-in functions | The staff already on payroll |
| 3 | User-defined functions | The specialist you build yourself |
| 4 | Lambda functions | Appears, does one job, vanishes |
| 5 | Higher-order functions (`map`, `filter`, `reduce`) | The one who commands the crew |
| 6 | Deeper mechanics | What makes you dangerous |
| 7 | Scale | Imagine 500 vaults with no crew |
| 8 | Quiz | Prove you are ready to lead the crew |

## Tech

Plain HTML, CSS and JavaScript in one file.
